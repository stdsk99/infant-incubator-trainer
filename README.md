# Infant Incubator Repair Trainer

สื่อฝึกซ่อมและบำรุงรักษาตู้อบทารก (infant incubator) แบบ interactive สำหรับวิชาเครื่องมือแพทย์
อ้างอิงโครงสร้างและหลักการทำงานของตู้อบแบบลมร้อนหมุนเวียนตระกูล GE Giraffe Incubator เน้นงานซ่อมและบำรุงรักษา

## โมดูล

1. หลักการทำงาน – ภาพตัดตู้อบ block diagram และแอนิเมชันเส้นทางสัญญาณ (ทำงานปกติ, พัดลมผิดปกติ, อากาศร้อนเกิน, สายวัดผิวผิดปกติ)
2. Alarm – 15 alarm พร้อมสาเหตุและลำดับการตรวจ
3. จำลองการซ่อม – โหมดเรียนรู้ (แอนิเมชันทีละขั้น) และโหมดสอบ (ตรวจอิสระ มีคะแนน) 8 เคส
4. การทดสอบหลังซ่อม / PM – ประสิทธิภาพอุณหภูมิ (IEC 60601-2-19), skin probe, ความชื้น, O₂, เสียงและลม, alarm, electrical safety (IEC 62353) พร้อมเครื่องคำนวณ โจทย์ฝึก และแบบบันทึกผล
5. ลำดับขั้นตอน – แตะเรียงขั้นตอนงาน 3 งาน
6. แบบทดสอบ – สุ่ม 20 ข้อจากคลัง 30 ข้อ

## โครงสร้างไฟล์

```
index.html            โครงหน้าเว็บ + ภาพ SVG ตู้อบในโมดูล 1
css/style.css         หน้าตาเว็บ + responsive (ใช้ร่วมกับ Infusion Pump Trainer)
css/incubator.css     ภาพตู้อบและภาพขยายชิ้นส่วน
js/app.js             เมนู, โมดูล 1–2
js/flow.js            โมดูล 1 แอนิเมชันเส้นทางสัญญาณ
js/learn.js           โมดูล 3 โหมดเรียนรู้ (ภาพตู้อบเคลื่อนไหว)
js/sim.js             โมดูล 3 โหมดสอบ + หน้าเลือกโหมด
js/pm.js              โมดูล 4
js/order.js           โมดูล 5
js/quiz.js            โมดูล 6
js/score.js, auth.js, cert.js   ระบบบัญชี คะแนน และใบรับรอง
data/config.js        ตั้งค่า URL ส่งคะแนน เกณฑ์ผ่าน และใบรับรอง
data/*.js             เนื้อหาทั้งหมด แก้ได้โดยไม่ต้องแตะโค้ด
apps-script/          Code.gs ที่รองรับทั้ง Infusion Pump และตู้อบ
```

## ระบบหลังบ้าน (ใช้ร่วมกับ Infusion Pump Trainer)

- ใช้ Google Sheet, Apps Script URL และ token เดียวกับ Infusion Pump Trainer
- ผู้เรียนใช้บัญชีเดียวกันทุกแอป สมัครและเข้าสู่ระบบที่เว็บหลัก (ศูนย์การเรียนรู้เทคโนโลยีทางการแพทย์)
- คะแนนทุกแถวมีคอลัมน์ `แอป` (`pump` หรือ `incubator`) คะแนนเดิมที่ไม่มีค่าในคอลัมน์นี้นับเป็น `pump`
- เกณฑ์ผ่าน แม่แบบเกียรติบัตร แท็บสรุป และโฟลเดอร์ PDF แยกกันตามแอป

**ต้องอัปเดต Code.gs ก่อนใช้งาน** ดูวิธีใน `apps-script/README.md`

## หมายเหตุ

- เนื้อหาและภาพทั้งหมดจัดทำขึ้นใหม่เพื่อการศึกษา โดยอ้างอิงหลักการทำงานจากเอกสารของผู้ผลิต ไม่ได้คัดลอกภาพหรือตารางจากคู่มือ
- ค่าใน service mode ราคาอะไหล่ และเกณฑ์ที่ระบุว่า "ตัวอย่าง" เป็นค่าสมมติ ให้ใช้ค่าจาก service manual ของรุ่นจริง
- GE และ Giraffe เป็นเครื่องหมายการค้าของเจ้าของ แอปนี้ไม่ได้เกี่ยวข้องกับผู้ผลิต
