# อัปเดต Apps Script ให้รองรับหลายแอป

`Code.gs` ในโฟลเดอร์นี้ใช้แทนตัวเดิมของ Infusion Pump Trainer ได้เลย ใช้กับ Google Sheet เดิม ข้อมูลเดิมไม่หาย

## ขั้นตอน (ทำครั้งเดียว)

1. เปิด Google Sheet ที่ใช้รับคะแนนอยู่ → **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางโค้ดจากไฟล์นี้ทั้งหมด → **บันทึก**
3. **Deploy → Manage deployments** → กดไอคอนดินสอที่ deployment เดิม → Version เลือก **New version** → **Deploy**
   - URL ของ Web app ยังเป็นอันเดิม ไม่ต้องแก้ `data/config.js` ของทั้งสองแอป
4. (ถ้าต้องการทดสอบ) เลือกฟังก์ชัน `testPost` แล้วกด Run ดูผลใน Execution log
5. รีเฟรชหน้า Google Sheet จะเห็นเมนู **ผู้ใช้** และ **เกียรติบัตร**

ครั้งแรกที่มีคนเข้าสู่ระบบ ระบบจะสร้างรหัสลับ `PEPPER` และ `TOKEN_SECRET` ใน Project Settings → Script Properties ให้เอง **ห้ามลบหรือแก้** ถ้าหายไป ผู้ใช้ทุกคนจะเข้าสู่ระบบไม่ได้

## สิ่งที่เปลี่ยน

- แท็บ `scores` มีคอลัมน์ที่ 14 ชื่อ `แอป` (เพิ่มให้อัตโนมัติเมื่อมีคะแนนใหม่)
- แถวเดิมที่ไม่มีค่าในคอลัมน์นี้นับเป็น Infusion Pump
- ตอนเข้าสู่ระบบ แต่ละแอปจะได้ประวัติคะแนนเฉพาะของแอปตัวเอง
- แท็บ `users` ใช้ร่วมกัน ผู้เรียนลงทะเบียนครั้งเดียวใช้ได้ทั้งสองแอป

## ออกเกียรติบัตรตู้อบ

เมนู **เกียรติบัตร → ตู้อบทารก (Infant Incubator)**
1. สร้างแม่แบบเกียรติบัตร (ครั้งแรกครั้งเดียว) → ได้ไฟล์ "แม่แบบเกียรติบัตร Infant Incubator Trainer" ใน Google Drive
2. สรุปผลผ่านเกณฑ์ → ดูแท็บ `สรุป ตู้อบ`
3. ออกเกียรติบัตรให้ผู้ผ่านเกณฑ์ → PDF อยู่ในโฟลเดอร์ "เกียรติบัตร Infant Incubator" รายชื่ออยู่ในแท็บ `เกียรติบัตร ตู้อบ` เลขที่ขึ้นต้นด้วย `IIT-`

ของ Infusion Pump ใช้แม่แบบ แท็บ และโฟลเดอร์เดิมทั้งหมด

## เพิ่มแอปใหม่ในอนาคต

เพิ่มรายการใน `APPS` ของ `Code.gs` (ชื่อ เกณฑ์ ข้อความเกียรติบัตร คำนำหน้าเลขที่ ชื่อแท็บและโฟลเดอร์) แล้วตั้ง `app` ใน `data/config.js` ของแอปใหม่ให้ตรงกัน และเพิ่มเมนูใน `onOpen`

## บัญชีผู้ใช้และรหัสผ่าน

- สมัคร เข้าสู่ระบบ และเปลี่ยนรหัสผ่าน ทำที่เว็บหลักที่เดียว แอปฝึกซ่อมไม่มีหน้าล็อกอินของตัวเองแล้ว
- รหัสผ่าน 8–16 ตัว ต้องมีตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก ตัวเลข และอักขระพิเศษ
- เก็บเป็นค่า hash (SHA-256 วนซ้ำ + salt รายคน + pepper ใน Script Properties)
- ใส่ผิด 5 ครั้งติดกัน ล็อก 15 นาที
- หลังเข้าสู่ระบบ ได้บัตรผ่าน (token แบบลงลายเซ็น HMAC) อายุ 30 วัน ใช้ส่งคะแนน ถูกยกเลิกเมื่อเปลี่ยนรหัสผ่าน รีเซ็ต หรือระงับบัญชี
- ผู้ใช้เดิมที่ใช้ PIN: ใส่ PIN เดิมในช่องรหัสผ่าน ระบบจะให้ตั้งรหัสผ่านใหม่ (ค่า PIN เดิมใช้ได้ครั้งเดียวแล้วถูกแทนที่)

แท็บ `users` เพิ่มคอลัมน์ สถานะ / ต้องเปลี่ยนรหัสผ่าน / ใส่ผิดติดกัน / ล็อกถึง / รุ่นบัตรผ่าน (เพิ่มหัวตารางให้อัตโนมัติ)
แท็บ `enrollments` เพิ่มคอลัมน์ สถานะ (ลงทะเบียน / ยกเลิก)

## เมนู "ผู้ใช้" (เปิดแท็บ users คลิกแถวของผู้ใช้ก่อน)

- **ดูข้อมูลผู้ใช้ที่เลือก**: สถานะบัญชี วิชาที่ลงทะเบียน ความคืบหน้า เกียรติบัตร
- **รีเซ็ตรหัสผ่าน**: ออกรหัสชั่วคราว (แสดงครั้งเดียว) ปลดล็อก และบังคับให้ผู้เรียนตั้งรหัสใหม่
- **ระงับ / เปิดใช้บัญชี**: ระงับแล้วเข้าสู่ระบบและส่งคะแนนไม่ได้ ข้อมูลยังอยู่ครบ
- **ยกเลิกการลงทะเบียนวิชา**: คะแนนเดิมยังเก็บไว้
- ระบบไม่มีคำสั่งลบผู้ใช้ ถ้าไม่ต้องการให้ใช้งานแล้วให้ระงับบัญชี
- แก้ชื่อ กลุ่ม หน่วยงาน ตำแหน่ง: พิมพ์แก้ในเซลล์ได้เลย ห้ามแก้รหัสผู้ใช้และรหัสผ่าน

## คำสั่งของ doPost

- `register` `login` `chpw` สมัคร เข้าสู่ระบบ เปลี่ยนรหัสผ่าน (คืนบัตรผ่าน)
- `portal` `enroll` ภาพรวมและการลงทะเบียนเรียน สำหรับเว็บหลัก (ต้องมีบัตรผ่าน)
- `app` `score` โปรไฟล์ ประวัติคะแนน และการส่งคะแนน สำหรับแอปฝึกซ่อม (ต้องมีบัตรผ่าน และลงทะเบียนวิชานั้นแล้ว)
- `verify` ตรวจสอบเลขที่เกียรติบัตร (ไม่ต้องล็อกอิน)
- คำสั่งที่ไม่รู้จักจะถูกปฏิเสธ

ผู้เรียนที่มีคะแนนอยู่ก่อนมีเว็บหลัก ระบบลงทะเบียนวิชาให้อัตโนมัติ (ยกเว้นวิชาที่ผู้ดูแลเคยยกเลิกไว้)
